# TermForge TODO：MMC 风格 MDI 工作台与 PowerShell 会话

日期：2026-09-05 | 范围：[统一 PRD](PRD-Phase1-ConPTY.md)

本表统一管理会话闭环任务 T01～T14 与 MDI 工作台任务 MDI-T01～MDI-T08。T09 复用 MDI-T02 的外壳；两组任务共享同一 PRD，均不得以占位实现代替验收。

执行顺序：先开展 T01 与 MDI-T01；完成容器验证后推进 MDI-T02～MDI-T04，同时按依赖推进会话任务。T09 在 T07、T08 和 MDI-T02 完成后接入单文档；MDI-T05 在 T07 与 MDI-T04 完成后接入多会话；完整终端控件就绪后完成 MDI-T06，最终由 MDI-T08 收尾。

所有实现任务初始均未完成。仅在满足完成标准并提供证据后勾选；已有接口、占位类或本文档本身不作为功能完成证据。P0 为闭环必需，P1 为本轮验收必需，均须完成后交付。

- [x] **T01 · P0 · 确认运行基线与测试入口**
  - 需求：FR-01；验收：AC-01。

  - 完成标准：构建和现有测试通过；缺失前置条件有明确记录，不以跳过替代验收。

- [x] **T02 · P0 · 明确会话契约和资源归属**
  - 需求：FR-03、05、06、07；验收：AC-02、05、06。
  - 依赖：T01。
  - 工作：结合 ITerminalSession 明确状态转换、重复调用、取消、事件线程和顺序、背压、退出通知时机、句柄所有权与关闭顺序；确认项目引用无环。
  - 完成标准：契约写入接口注释或开发文档，覆盖 PRD 生命周期约定；对已有接口的必要变更说明原因。

- [x] **T03 · P0 · 实现原生资源和 Job Object 封装**
  - 需求：FR-01、07；验收：AC-05、06、09。
  - 依赖：T02。
  - 工作：实现管道、ConPTY、进程属性列表与进程句柄管理；实现 Job 的关闭清理配置；保证进程在执行用户代码前纳入 Job。
  - 完成标准：每个资源都有明确释放者；任意中间步骤失败都能回收此前资源；Job 绑定失败不会留下运行中的 Shell。

- [x] **T04 · P0 · 实现启动与配置传递**
  - 需求：FR-01、02、06；验收：AC-01、06。
  - 依赖：T03。
  - 工作：新增 ConPtyTerminalSession，支持 ShellProfile 配置；处理带空格路径和环境变量继承覆盖；实现 Created → Starting → Running / Failed。
  - 完成标准：无 UI 场景能启动真实 pwsh；目录和变量生效且不污染宿主；重复启动被拒绝；失败原因可诊断。

- [x] **T05 · P0 · 实现双向 I/O、解码和中断**
  - 需求：FR-03、04；验收：AC-01、02、03。
  - 依赖：T04。
  - 工作：实现文本与字节写入、独立输出读取、跨块 UTF-8 解码、输出事件和 Ctrl+C 输入；明确并发写入顺序。
  - 完成标准：真实执行结果可验证；中文和 Emoji 跨块不损坏；长命令可中断并继续使用同一会话；UI 不参与底层测试。

- [x] **T06 · P0 · 实现尺寸调整**
  - 需求：FR-05；验收：AC-04。
  - 依赖：T04。
  - 工作：复用 TerminalDimensions 校验，调用 ResizePseudoConsole，仅成功后更新尺寸；处理非运行状态和调用失败。
  - 完成标准：三组尺寸经 Shell 侧观测一致；无效输入不破坏会话。

## MDI 工作台任务

- [x] **MDI-T01：验证容器方案**
  - 依赖：无；对应 MDI-02、03。
  - 用 3 个模拟文档验证内部重叠、拖动、缩放、层叠、双向平铺、最小化、最大化及还原。
  - 完成标准：提交可运行原型和选型记录，明确现有依赖覆盖能力及需要补充的部分；仅标签和停靠不算通过。

- [x] **MDI-T02：搭建 MMC 风格外壳**
  - 依赖：MDI-T01；对应 MDI-01。
  - 实现菜单、工具栏、导航树、文档区、状态栏及可隐藏的属性/日志面板。
  - 完成标准：展示完整布局，缩放主窗口时主要操作可访问；T09 复用该外壳，不另建独立单表单界面。

- [x] **MDI-T03：实现文档管理与活动上下文**
  - 依赖：MDI-T02；对应 MDI-02、06。
  - 管理文档集合、唯一 ID、标题、活动文档及关闭命令；联动导航树、窗口菜单、属性面板和键盘切换。
  - 完成标准：3 个文档可独立新建、激活、关闭，菜单和输入焦点始终对应活动文档；再次选择已有会话不创建副本。

- [x] **MDI-T04：完成子窗口布局行为**
  - 依赖：MDI-T03；对应 MDI-03。
  - 实现拖动、缩放、重叠顺序、层叠、上下/左右平铺和窗口状态转换。
  - 完成标准：最大化后可切换文档，最小化后可找回，关闭一个文档后正确激活剩余文档；记录操作验收结果。

- [x] **MDI-T05：接入独立终端会话**
  - 依赖：MDI-T04、T07；对应 MDI-04、05、08。
  - 每个终端文档绑定一个独立会话；将布局生命周期与进程生命周期分离。
  - 完成标准：A/B/C 命令和输出隔离；布局操作不改变会话和进程 ID；关闭 A 不影响 B/C；主窗口关闭后所有会话清理。

- [ ] **MDI-T06：接入完整终端控件并验证焦点和尺寸**
  - 依赖：MDI-T05、后续 Buffer/VT/Renderer/Input 实现；对应 MDI-04、05、06。
  - 以原生终端控件替换调试视图，按实际文档内容区调整终端行列；处理最小化和恢复。
  - 完成标准：连续切换、平铺、最大化、还原后键盘目标正确，Shell 感知尺寸正确，隐藏或最小化不停止会话。

- [ ] **MDI-T07：保存与恢复布局**
  - 依赖：MDI-T05；对应 MDI-07。
  - 保存文档配置、位置、尺寸、状态、活动文档及面板可见性；恢复时校正超出工作区的窗口。
  - 完成标准：重启后布局可用；会话明确为新启动；不误导用户认为旧进程或未完成命令已恢复。

- [x] **MDI-T08：完成工作台验收与文档同步**
  - 依赖：MDI-T06、MDI-T07；对应 MDI-01～08。
  - 建立 `docs/validation/mdi-workbench.md`，逐项记录界面、会话隔离、布局、焦点、恢复和清理结果。
  - 完成标准：8 项需求均有证据；更新 README 和总体阶段进度，分别标记 MDI、终端能力和大规模并发状态。
