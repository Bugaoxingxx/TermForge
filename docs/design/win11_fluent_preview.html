1. 外壳原生化 (Fluent Shell)

废弃原有自绘写死 AeroGlassBrush 标题栏，改用 Windows 11 原生 Mica / 系统 Caption，恢复系统窗口阴影与 12px 圆角。

鼠标悬停最大化按钮唤出 Win11 原生 Snap 飞窗，支持 50/50 分割、70/30 主从、四格象限，完整保留系统操控手感。

3. 视口绝对隔离 (Viewport Guard)

严格维持 #0C0F14 高对比度视口规范，坚决不加任何材质模糊与圆角裁剪，确保 ConPTY / VT 零渲染损耗。

4. .NET 10 LTS 契约

7 个项目全面对齐 net10.0-windows，利用官方 ThemeMode=System 与 Segoe Fluent Icons 体系。
