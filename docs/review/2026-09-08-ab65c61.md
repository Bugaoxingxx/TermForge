## 发现

### [P1] `ThemeMode=System` 没有配套的深色 token

- 位置：`src/AgentTerminal.App/App.xaml`、`App.xaml.cs`、`Themes/Colors.xaml`、`tests/.../ThemeResourceSmokeTests.cs`（`FluentThemeTokens_ShouldSupportLightAndDarkSemantics`）
- 问题：应用级已设 `ThemeMode=System`，但 `Colors.xaml` 仍是浅色常量（如状态栏 `#F3F3F3`、正文 `#1F1F1F` / `#242424`）。冒烟测试只断言键存在，不覆盖深色。`MainWindow.xaml` 菜单仍硬编码 `Foreground="#1E395B"`。`WM_SETTINGCHANGE` 只更新 DWM 沉浸式暗色属性，不切换产品画刷。
- 影响：未模板化的 Menu/ScrollBar 会随系统变深，工具栏/面板/状态栏仍浅色，深色模式下混搭。
- 建议：补深色 `ResourceDictionary`（或按 `IsDarkModePreferred` 切换 MergedDictionary）；在深色落地前不要开 `ThemeMode=System`。

### [P1] 去掉自定义标题栏，改用系统/Fluent 原生 caption

- 位置：`src/AgentTerminal.App/Themes/MainWindowChrome.xaml`、`MainWindow.xaml.cs`（系统菜单/命令绑定）、FlaUI 标题栏按钮页面对象
- 问题：当前 `WindowStyle=None` + `WindowChrome` 自绘 46×32 按钮，是为了消双重标题按钮。代价是丢失系统标题栏手感：Snap Layouts、系统投影与最大化留边、沉浸式暗色标题栏由 DWM 直接绘制。这与 `modernize-win11-fluent-ui` 路径 A（外壳交给系统）不一致。**不要**再用 `HTMAXBUTTON` 把自绘栏补成半套系统行为。
- 建议：
  - 去掉自绘 caption 模板（图标/标题/最小化/最大化/关闭）。
  - 恢复默认 `WindowStyle`（`SingleBorderWindow`），`UseAeroCaptionButtons` 交回系统；客户区继续 `GlassFrameThickness` / Mica 透明以透出材质。
  - 删除仅为自绘栏服务的 `SystemCommands` 绑定与 `OnShowSystemMenu`。
  - UI 测试改为断言系统窗口模式（`IWindowProvider` 最小化/最大化/关闭），不再依赖 `MainWindow.BtnMinimize` 等自绘 AutomationId。
  - 去掉自绘栏后，重新评估 `WM_GETMINMAXINFO` 补偿是否仍需要；系统 chrome 通常自己处理工作区。

### [P1] `WM_GETMINMAXINFO` 设 `handled = true`，且 hook 只加不卸

- 位置：`src/AgentTerminal.App/Infrastructure/WindowBackdropHelper.cs`（`ApplyBackdrop`、`WndProc`）
- 问题：每次 `ApplyBackdrop` 都 `AddHook`，窗口关闭没有 `RemoveHook`。`handled = true` 会截掉 WPF 自己的 min-track 处理。`ptMaxPosition` 使用 `Math.Abs(rcWork - rcMonitor)`，多显示器组合下不如有符号差值稳妥。
- 影响：在仍使用 `WindowStyle=None` 时，重复调用会叠 hook，可能吃掉 `MinWidth`/`MinHeight`。
- 建议：与「去掉自定义标题栏」一并处理。恢复系统 chrome 后优先删除这段最大化补偿；若仍保留 hook，只挂一次并在 `Closed` 卸掉。

### [P3] 强调色用错了系统色

- 位置：`Themes/Colors.xaml`（`FluentAccentBrush`）
- 问题：绑定 `SystemColors.HighlightColor`（选区蓝），不是 Windows 强调色。
- 建议：用 `UISettings.GetColorValue(UIColorType.Accent)` 或等价 API。

### [P3] 关于对话框和注释仍写 Win7

- 位置：`MainWindow.xaml.cs`（`OnMenuAboutClick`）、`MainWindow.xaml` 注释
- 问题：关于框仍为「Windows 7 Aero MMC… Version 0.3 | 2026-09-05」。
- 建议：改为 Fluent / 当前版本表述。

### [P3] UI 测试 `Find()` 吞异常并从桌面重找窗口

- 位置：`tests/AgentTerminal.UITests/Pages/MainWindowPage.cs`
- 问题：空 `catch` 把定位失败收成 `null`，再靠加长 timeout；桌面级 `ByAutomationId("MainWindow")` 多实例时可能抓错窗。
- 建议：保留重试，但不要吞掉非超时异常；限定在当前进程窗口。

### [P3] 其它

- `ThemeMode` 在 XAML 与 `OnStartup` 设了两次；`WPF0001` 项目级 `NoWarn` 再加 pragma，留一处即可。
- `global.json` 文件末尾缺换行。
- `WindowBackdropHelper` 无单测（版本门闩、回退背景）。
- Win11 22000～22620：圆角和沉浸式暗色可用，当前整段跳过，只走纯色回退。
